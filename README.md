# jump-n-run

An experiment to track how a model's game design skills progress over time.

Each iteration adds or refines gameplay mechanics, starting from a minimal canvas placeholder and evolving toward a more complete jump-and-run game.

## Current state

A basic HTML5 canvas "game" placeholder — a static scene with a character and a platform, no interactivity yet.

## Running locally

Open `src/index.html` in a browser. No build step required.
